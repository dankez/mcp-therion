Hi all,

new version of therion is available (see the file changes for new features).

We introduced a new, more standardized version numbering scheme.
Stable releases are numbered using MAJOR.MINOR combination, unstable
releases get the third nuber: MAJOR.MINOR.BUILD_NUMBER. We also
dropped the leading zero because Therion does not deserve it any more
and there is no space left for it in the new numbering.

Therion book contains new chapter Case studies, which documents some
of the features (http://therion.speleo.sk/downloads/thbook.pdf). It is
rather experimental now, but could be expanded to cover all
substantial areas of therion usage. If you compile thbook by yourself,
you need to compile samples in the "samples" directory before
compiling thbook to include this chapter.

thTeam

point)

sheet for the elevation is labelled 5 V, (not 5 X) and that because my
elevation is looking west, the labels increase in the wrong direction.

I think there is a bug in the labelling of the atlas pages in elevation.
There needs to be a means of reversing the direction that the ABC, 123
increase in, so that plans and elevations can use a consistent atlas page
labelling scheme.

 

These effects are the same for version 5.2 and 0.5.1

#Atlas plan origin definition

Subject: [Therion] Atlas exclude-pages syntax issue and solution
Message-ID: <000601c8ff84$57010630$9425f6d2@JUICEBRAIN>

A minor 'character' issue with the exclude-pages statement when there is
only one page to exclude;

 

   exclude-pages on [4]  

 

and a number of similar arrangements (without the brackets for example)
results in the following error at compile time;

 

   making atlas ... D:\Program Files\Therion\therion.exe: error -- Invalid
character in the exclusion list!

 

The solution is to add a comma;

 

   exclude-pages on [4,]  

 

Regards

Bruce
