Well, this is not yet possible (entering station without name), but it
is in the TODO list. Currently only SPLAY flag to shots is supported.

Especially when using devices like DistoX, then there are a lot of
such measurements. I believe, it will be done soon. Currently, we see
two kinds of such a "splay" shots - one pointing to the walls and the
other pointing to the features (like blocks, huge stalactites etc...).
So probably syntax will be like

1.0   -    2.33 123.3 0.1 # from tape compass clino

for splay shots pointing to the wall and

1.0  .    2.33 123.3 0.1 # from tape compass clino

for splay shots pointing to the features. But it needs to be implemented.

Supporting such a measurements in a 3D volume model generation is
completely different story - I have no idea right now how it could be
implemented :( But when the step 1 will be done, I will start thinking
of it. At least estimating LRUD from such shots when LRUD data are
missing should be relatively easy.

Regards, S.

It looks, using survey grades will change in therion in the near
future. The reason is, that in current configuration, it is not very
clear, how to use it. We have studied the problem a little bit and it
looks, that there are more or less same survey grades used around the
world. So our suggestion is to use just simple

grade N

option in centerline, where N will be survey grade from 0 - 7, where
1-6 = BCRA 1-6, 7 = BCRA X and 0 will be data without any quality
(e.g. position of cave nobody is able to locate now). This grade
should be specified in each centerline object. And such a
configuration will allow doing statistics on survey data from
different sources. Of course, it will still be possible to refine data
quality using "sd" option, but grades will remain the same for all
survey data in therion.

If you have any comments, please let us know.

Regards, S.

Ps.: the metapost code I used:

def PenXXL = pencircle scaled (2.4*u/10) enddef;

def l_pit (expr P) =
  T:=identity;
#draw the two lines
  pickup PenXXL;
  thdraw P;
  thclean P;
  pickup PenX;
  thdraw P;
  pickup PenC;
  thdraw P withcolor (1,1,1);

 # draw triangles
  laenge:= arclength P;
  symsize:=0.5u;
  triangle_width:=symsize/2;
 
  pair l_triangle;
  pair f_triangle;
  pair test;
  path triangle;
  path draw_triangle;
  triangle:= (-triangle_width/2,0) -- (triangle_width/2,0) --
                (0,symsize/2) -- cycle;
  cur:=(symsize);
 
  t := arctime (cur) of P;
  f_triangle := (point t of P +.05u*unitvector(thdir(P,t) rotated 90));
  thfill triangle rotated angle thdir(P,t) shifted f_triangle ;
  l_triangle := f_triangle;
 
  for cur=(symsize) step 0.1 until laenge:
    t := arctime (cur) of P;
    test := (point t of P +.05u*unitvector(thdir(P,t) rotated 90));
    my_dist := distance(test,l_triangle);
   # show my_dist;
    if abs(my_dist-symsize) < 0.05u:
    draw_triangle:=triangle rotated angle thdir(P,t) shifted test;
      if xpart (draw_triangle intersectiontimes P) < 0:
        thfill triangle rotated angle thdir(P,t) shifted test;
        l_triangle:= test;
      fi;
    fi;
  endfor;
enddef;
