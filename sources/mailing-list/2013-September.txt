OK, so this issue here is that you get 'error 768' if you configure
therion to use fonts that are not installed.

Default upstream therion set up to use latin, czechslovak and cyrillic
fonts, and needs them installed, even if only latin fonts/chars are
actually used. As those two fonts are another 16MB I changed it a long
time back to not install these by default, and added lines to
/etc/therion.ini to easily enable them, along with an explanation
about this in Debian.readme. And the two packages
texlive-lang-czechslovak texlive-lang-cyrillic are in 'Suggests:'

It would appear that Andrew had uncommented these lines but not
actually installed the corresponding font packages. I'll modify the
file to make clear in the comment that the lang packs need installing.

The alternative would be to enable all the fonts by default and
have the lang packs as hard dependencies. That would match upstream
better, but I'm inclined to leave the Debian packaging as-is, unless
someone can persuade me that it should be changed.

input layout_foo

I recently discovered 'point stalagmites' (plural) which is presumably new
in 5.3.11 (but it may have been around much longer).

Now that I've started using it I have discovered that the legend text has
not been refined for these, which is easy to correct using the following
statements in thconfig file.

 

text en "point stalactites"      "many stalactites"

text en "point stalagmites"     "many stalagmites"

 

Would be nice to have corrected in future 5.3.12, together with mention of
the plural symbols in the Therion Book.

 

Happy caving

Bruce
