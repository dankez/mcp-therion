Firt of all compile your data with parameter -d in Command Line Options of compiler window. Thbook page 58: 
Options:
• -d ◃ Turn on debugging mode. The current implementation creates a temporary directory
named thTMPDIR (in your system temporary directory) and does not delete any
temporary files.

In the thTMPDIR directory should be all files Therion created during compilation. The one with the highest number is the last one which the Therion was able to created.

Check it for error.
