Just in case this might be useful for someone, there was an issue with the proj installed by homebrew not pointing to proj.db, this can be corrected by adding :
export PROJ_LIB=/opt/homebrew/Cellar/proj/8.2.1/share/proj
in your .XXXsrc 
In might just be my environment.

Hi,

this is just the first iteration of volume calculation. It calculates the
volume of either the 3D model created from the LRUD envelope or the volume
of scrap 3D models.

If there are splay shots in the dataset - currently this creates 2 problems:

1. 3D envelopes of survey stations are mixed and exported as regular map
scraps - a new version of LOX file needs to be created to separate them.

2. they overlap with map scraps and also each other - therefore volume is
several times overestimated.

So far, if you have splay shots in your datasets, to get some reasonable
numbers, you should:

1. export 3d model with "-wall-source maps" -> this will create 3d model
consisting only of scraps from maps and then scraps 3d volume should be
more or less OK, LRUD will be 0

2. export 3d model with "-wall-source centerline" -> then only LRUD
readings will be used. You may use "Tools/Options/Extrapolate all missing
wall information" to add LRUD envelope where it is missing.

Unfortunately, there is no easy way of calculating volumes from splay
shots. There is a new version of LOX file format missing and some 3D union
algorithm.

S.

Tarquin

There are a number of size settings listed in the default xtherion.ini:

## size of point

# set xth(gui,me,point,psize) 4

 

## size of line point

# set xth(gui,me,line,psize) 3

 

## line width

# set xth(gui,me,line,width) 3

 

## size of line control point

# set xth(gui,me,line,cpsize) 4

 

Adjusting these did occur to me, but I was being lazy and asking first, rather than experimenting.  I was hoping to keep the small size but have a large snap distance.
