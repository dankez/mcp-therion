I think that there might be a way to do this without falsifying the data.

I wrote a rough and ready script to extract the names of cross sections 
from therion files and place the cross section point in a grid. That I 
manually arranged into sections as can be seen on the goughs survey
(I would put in a link but it does not seem to be on the ubss site any 
more, I'll have to find somewhere else to put it.)

But the script is still here

https://bitbucket.org/AndrewA/therion-xsectionextractor/src/master/

It was written to do a job, there are no bells or whistles.

If the cross section points are placed in a grid at half the scale of 
where they actually want to be and then a second survey is produced at 
twice the scale by hiding the right symbols in each file and placing the 
outputs on top of each other you would get the cross sections at twice 
the scale. You can probably even do the combination in therion, same as 
putting an elevation an plan together.

No idea if this actually works and setting up to try would be a lot of 
work, but hopefully this thought experiment will give you a starting 
point to a solution

Andrew

   cs utm30
