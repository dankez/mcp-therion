* Windows: language selection is not kept after app restart. [reported by Edvard]
* No app icon in Windows version.
* Add a publisher for Mapiah Windows installer.
* Changing the line segment type of several line segments of different types wouldn't change any.
* Trying to move a control point immediately after transforming a straight line segment to B?zier curve throws and the control point does not move.
* Ctrl+K keyboard shortcut (Show keyboard shortcuts) not working at TH2 file edit page. [reported by Edvard]
* During new line creation, on B?zier line segments, the control points are presented but are not usable. [reported by Edvard]
* When creating a line, any line segment, if dragged to become a B?zier, leaves a shadow red straight line segment behind during drag.
* Orientation/LSize arrows presented on all lines when editing a line, not only on the line being edited.
* Removing spurious &lt;a&gt;&lt;/a&gt; tags from portuguese help page.
* Infrastructure maintenance:
* flutter upgrade to 3.38.9.
* flutter pub upgrade --major-versions
* Migrated thFileWidgetKey to getTHFileWidgetGlobalKey() at TH2FileEditController. * Created constants to set the help page names.

If anybody is interested in testing/using it, reports are welcome.
